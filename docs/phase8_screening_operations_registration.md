computation; all old registrations and the running chain stay unchanged.

new source, export its strictly validated terminal evidence once. Preserve
raw records, original Git blobs/modes, input bytes and old modules. New
launches prove those originals are unchanged and permit only the exact new
paths in a committed source-extension manifest. Only then may the read-only
old workflow validator use its proven original identity. New sources are
frozen separately; artifact-only commits do not waive byte checks.

functions, records the actual selected module in every C++ worker, and writes
a fresh receipt. Supplied files without that provenance remain pending
verification; no past receipt is invented. Historical outputs are preserved.

power, existing ownership, changed dependencies or source drift refuses or
invalidates work. Reserved tests, partial output and failures are retained.
Release needs proven child exits and complete terminal evidence. Heavy tests,
training and timings wait for the old benchmark lease to end.

All fixture tests are written before launch and run after the chain.

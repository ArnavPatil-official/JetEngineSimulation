# pyCycle 4.4.0 generic maps (exported)

Fan, LPC, HPC, HPT and LPT maps of the pyCycle high-bypass turbofan example,
exported unchanged by `scripts/phase8/pycycle/export_maps.py` from the pinned
`catjet-pycycle` environment. Source: pyCycle (https://github.com/OpenMDAO/pyCycle),
tag 4.4.0, NASA Glenn Research Center / OpenMDAO, Apache License 2.0. Each JSON
records the source file name and SHA-256. Used by P8.4
(`docs/phase8_p84_registration.md`) as generic scaled maps; they are not Trent
data and not validation data.

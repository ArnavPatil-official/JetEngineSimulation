# Sajben data-reality audit (P4.1) — 2026-09-17

Generated by `scripts/validation/sajben_data_audit.py` at git `e40d05c`. Gate metric: held-out wall-Cp shape-L2 from `sajben_validation.py` (`_normalise_01` both profiles to [0,1], then `_l2_relative`), pre-registered bands < 0.10 pass / 0.10–0.25 partial / > 0.25 fail (`docs/plan.md`, P4.3).

## Verdict

**GO, on route (a).** The existing training set cannot reach the gate for two independent reasons (§1), and its analytic ceiling on the gate metric is **0.154** (§2) — above 0.10 for the best shock station the generator can produce, so the recorded 0.714 / 0.723 was a domain-mismatch artifact, not a training failure. The NASA archive already ships a converged Spalart-Allmaras RANS solution of the weak-shock case on the same 81×51 grid; it decodes without new dependencies and scores **0.089 / 0.084** (upper / lower wall) against the experiment on the gate metric (§3). That is the training data for P4.3.

## 1. What `master_shock_dataset.pt` contains

`data/processed/master_shock_dataset.pt` (sha256 `f4f01c42dd52906b…`): 128,061 rows = 31 cases × 81 × 51, 6 inputs / 9 targets, sample weights [1.0, 5.0].

| Question | Measured | Meaning |
|---|---|---|
| Rows with v ≠ 0 | 86.1 % (max \|v\| 64.4 m/s vs max \|u\| 489 m/s) | v is `_estimate_transverse_velocity`: inviscid streamline deflection from the wall slope, not a solved momentum field |
| Wall-normal variation of ρ, u, P, T within a station | ρ 0.0e+00, u 0.0e+00, P 0.0e+00, T 0.0e+00 (relative span, max over all stations) | zero by construction — `_pack_case` broadcasts the 1-D axial solution with `np.repeat` over all 51 wall-normal points |
| u(wall) / u(centreline) | 1.000 – 1.000 | no row encodes a boundary layer; the wall velocity equals the core velocity everywhere |
| μ_eff | 1.17e-05 – 1.81e-05 Pa·s; max deviation from Sutherland(T) 9.7e-06 % | molecular viscosity only — no eddy viscosity, hence no turbulence model |
| Target columns all-NaN | [5, 6, 7] | Reynolds-stress slots; masked out of the data loss, docstring calls them zero-padded (P4.7 fix) |
| Inputs that are a single constant | ['A5', 'A6', 'P0', 'T0'] | **the flow case is not identifiable from the inputs** |
| Unique input rows | 4,131 of 128,061 — each input row repeats 31× with different targets | the dataset is a one-to-many map |
| Input rows whose P target varies > 10 % across cases | 100 % (max spread 124 %) | a mean-squared regressor converges to the case-average, i.e. a smeared ramp, not a shock |

**Finding 1a — no physics.** Every row is a quasi-1D inviscid, adiabatic, laminar-viscosity state broadcast across the channel. The Sajben benchmark measures shock/boundary-layer interaction: a curved-wall suction peak, a λ-shock foot smeared over ~1 H, asymmetric upper/lower wall recovery, and no-slip velocity profiles. None of that is in the training signal.

**Finding 1b — no conditioning variable.** `A5, A6, P0, T0` are identical for all 31 cases, so the back pressure that sets the shock position is not an input. The same (x, y) carries 31 different pressures. This is not fixable by epochs, architecture, or loss weights: the target is not a function of the inputs. Any model trained on this set is fitting the average over shock positions (green dotted curve in the figure).

## 2. Analytic ceiling of the quasi-1D generator on the gate metric

Experimental conditions from `sajben.dat.*`: P₀ = 135008 Pa, T₀ = 292.0 K, M_in = 0.46; experimental exit P/P₀ = 0.819. All 63 diverging-section shock stations were scored (`outputs/sajben_data_audit_ceiling.csv`). A 1-D solution has identical upper and lower wall pressure, so it cannot reproduce the measured wall asymmetry at all.

| Quasi-1D candidate | Upper L2 | Lower L2 | Mean | Band |
|---|---|---|---|---|
| Best of all 63 shock stations (x_shock/H = 1.59, M₁ = 1.258) — **the ceiling** | 0.170 | 0.138 | 0.154 | 0.10–0.25 (gate band: partial) |
| Station selected by the experimental back pressure (exit P/P₀ = 0.820, x_shock/H = 2.53) | 0.313 | 0.300 | 0.307 | above 0.25 (gate band: fail) |
| Dataset conditional mean (what MSE regression on the one-to-many set converges to) | 0.486 | 0.500 | 0.493 | above 0.25 (gate band: fail) |
| Best shock station under the scorer's current x-mapping (H/2, see §4) | 0.261 | 0.257 | 0.259 | — |

**Finding 2.** The ceiling is 0.154 (above the 0.10 gate) for the single most favourable member of the training family; the member the physics actually selects (matching the measured exit pressure) scores 0.307, and the profile a regressor would converge to scores 0.493. **No model trained on this data can pass the gate; this is computed, not argued.** The recorded 0.714 / 0.723 for `le_pinn_sajben.pt` is therefore a domain-mismatch artifact. What a quasi-1D inviscid solution *can* reproduce, at best: the isentropic run-up to the throat, a sharp jump at one chosen station, and the subsonic recovery level. What it cannot: the upper/lower asymmetry, the smeared shock foot, the post-shock plateau, and any velocity profile. Note that the inviscid solution that matches the measured exit pressure puts its shock at x/H = 2.53, downstream of the measured shock near x/H ≈ 1.4: the boundary-layer displacement and total-pressure loss that set the real shock position are exactly the physics the generator lacks.

## 4. A scorer defect found while reproducing the metric

`compute_wall_cp_errors` and `compute_velocity_profile_errors` in `sajben_validation.py` set `H_m = sqrt(A5/π)`. With `A5 = π (H/2)²` from `build_sajben_grid`, that is the throat *radius* — half the throat height. Both functions then map the experimental x/H and y/H with it, so every experimental coordinate is placed at half its true distance from the throat (the measured shock at x/H ≈ 1.4 is compared against the model at x/H ≈ 0.7). The velocity profiles are compressed the same way. Every Sajben number in the repo — 0.714 / 0.723 and the fine-tuned 0.805 / 1.091 — was scored under this mapping. The fix is one line per function (`H_m = 2·sqrt(A5/π)`, or pass the geometry's `H_m` through) and lands in P4.2 before any checkpoint is re-scored, with old- and new-metric numbers reported side by side. It does not change the conclusions above: the table in §2 shows the quasi-1D ceiling under both mappings, and §3 shows WIND under both.

## 5. Routes and decision

| Route | What it gives | Cost | External-validation claim | Verdict |
|---|---|---|---|---|
| **(a) NASA/WIND archive solution** | one converged S-A RANS field, 4 131 points, ρ u v P T μ_l μ_t, same grid, weak-shock case only | done — `wind_cff.py`, no dependency | **kept**: trained on CFD, scored on an independent experiment | **adopted** |
| (b) Fresh 2-D RANS (SU2) | a parametric family over back pressure; reusable | SU2 install + mesh + case setup + convergence study; the vendored `nozzle_flow_cfd-main` is a generic AI-generated SU2 desktop GUI with de Laval templates and self-declared minimal testing, with no Sajben case | kept | not needed for the gate; the natural follow-up if a back-pressure-parametric surrogate is wanted later |
| (c) Train on the experiment with a declared split | 71 wall taps + 116 LDV points | trivial | **forfeited** — held-out set is small and spatially correlated | rejected while (a) exists |

**Decision: route (a).** Justification: it is the only route that is both already in the repo and physics-complete; it keeps the external-validation language because the experiment never enters training; and it makes the P4.3 leakage guard trivial by construction — a checkpoint's recorded training source is the WIND file hash, and the scorer refuses any checkpoint whose provenance names `data.Mach46.txt`.

**What route (a) changes for P4.3, recorded now:**

- The model becomes a single-condition surrogate (weak-shock case, one back pressure). The preprint must say so; it is not a parametric nozzle model.
- Training inputs must not repeat the current defect: with one case, `(x, y)` alone identify the target, and `A5, A6, P0, T0` are constants. Either drop them or keep them as documented constants.
- The RANS residual in `_safe_physics_loss` overwrites `μ_eff` with Sutherland molecular viscosity (`le_pinn.py` ~L1469), so on RANS data the physics term is a laminar residual that contradicts the data in the boundary layer. P4.3 must feed `μ_l + μ_t` from the WIND field (or drop the viscous term) before the physics weight is turned on.
- Reynolds-stress target columns 5–7 stay zero (not NaN) unless derived from μ_t via Boussinesq.
- The inflow column (i = 0) carries the uniform-inflow condition imposed on no-slip walls, which produces a wall-pressure spike at the two corner points (visible at x/H ≈ −4 in the figure). The experimental taps begin just downstream of it, so the gate metric never samples it; the P4.3 training set should either exclude i = 0 or document that it is a boundary artifact.
- The strong-shock case is not in the archive; nothing here supports claims about it.
